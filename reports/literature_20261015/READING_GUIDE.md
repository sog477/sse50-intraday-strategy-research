# 一天的逐笔订单数据，值得问哪些不寻常的问题？

检索与核验日期：2026-10-15。数据对象是本项目2026-09-23的50只个股Order/Trade/Snapshot，不是指数本身可供挂单的订单簿；也不把这50股自动等同于上证指数全体成分及其权重。

## 交付及核验范围

本次整理38条文献：37条至少核过一手摘要或原稿相关内容，另1条只核过书目、未用作结论依据。12条打开全文核对相关段落，25条为原始摘要/正文片段层级，1条仅书目；没有声称逐篇通读。出版商、arXiv、作者大学主页、监管机构或原稿仓储为主，二手博客不作为研究结论来源。17个正式出版DOI另与Crossref出版商提交的元数据核对，原始结果保存为`metadata_crosscheck.json`。

完整目录见[38条逐篇记录](CATALOG.md)，机器可读书目见`papers.json`。每条都区分原文切口、本地可问的问题、适配程度和缺失字段。

**论文真实存在，不等于其结论已被我们复现。**工作论文不是已通过同行评审的文章；最前沿的2026文献明确保留这一身份。我们优先找的是能用具体订单解释的好问题，不以模型复杂度或论文数量充当贡献。

## 二、我最看重的“新鲜想法”

### 1. 挂单容易成交，反而可能是坏事

Albers等的*The Market Maker's Dilemma*用币安实盘小额挂单实验研究成交概率与成交后收益的冲突。[2025预印本及全文](https://arxiv.org/abs/2502.18625)

本地改写：预测未来上涨，与能否靠买限价单获得有利成交，是两件事。应该同时展示未成交比例、成交等待及成交后标记收益，而不是只画所有时点的价格预测相关性。A股费用、持仓约束和模拟成交的不确定性还要另外处理；不移植原文利润数字。

### 2. 买一都少了1,000股，但少在“我前面”还是“我后面”，意义不同

Dahlström等的*The determinants of limit order cancellations*把队前和队后深度分开讨论。[2024卷期期刊，2023在线](https://onlinelibrary.wiley.com/doi/10.1111/fire.12363)

本地改写：队前量减少带来排队进展，队后量减少可能意味着同侧支持撤离。将二者相加会抹掉区别。同价新单按FIFO排在已有单后面；不能凭空构造“同价新单插到我前面”的事件。我们已有逐笔队列，可以直接测这些差异，但缺原文用于身份、库存控制的字段。

### 3. 大跳价可能是盘口有洞，不一定是单子大

Farmer等的*What really causes large price changes?*在伦敦订单簿中强调价格档位间的缺口。[2004修订原文](https://arxiv.org/abs/cond-mat/0312703)

本地改写：在成交量相近时，比较冲击前买一/买二或卖一/卖二的空档。还要区分“解释刚刚跳价”和“事前预测下一次跳价”；删掉最优档后价格必然跳到下一档，不能把这一机械关系当预测创新。

### 4. 撤单很多，可能是在努力成交

Hasbrouck和Saar的*Technology and liquidity provision*与*Low-latency trading*研究短命限价单及连接报撤消息的行为链。[2009作者原稿](https://pages.stern.nyu.edu/~jhasbrou/Research/Working%20Papers/HS6.pdf)、[2013期刊原稿](https://pages.stern.nyu.edu/~jhasbrou/Research/lowLatencyTrading/lowLatencyTradingHasbrouckSaarJFM.pdf)

本地改写：一次撤单之后，可能追价、同价补回、退到远档或退出；这些不能混成一个撤单率。公共消息连接只能叫“候选行为链”，不赋予账户或母单身份。这比看某个整数股数就猜机构更扎实。

### 5. 排在队尾的风险，不只是等得久

Moallemi与Yuan的*A Model for Queue Position Valuation in a Limit Order Book*分别考虑排队位置的当前和未来价值。[2016/2017工作稿](https://moallemi.com/ciamac/papers/queue-value-2016.pdf)

本地改写：对同价前后排订单，不能仅比较是否成交，还需比较成交后的价格。用模拟单可减少真实订单自身选时带来的混杂，但固定历史路径也有误差；不能声称等同原文估值或实盘试验。

### 6. 有些补单，可能在你看到价格变化前已经出发

Albers等的*The “Neutrinos” of the Order Book*是2026年工作论文，原始登记摘要涉及Hyperliquid完整消息及被拒绝的post-only指令。[较新登记](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7162966)、[作者大学主页交叉核对](https://math.ucla.edu/~mihai/index.html)

这个想法很新，但我们的数据没有拒单、发送时刻和接收确认。**不能从“补单来得快”推断“早已在途”，也不能估计原文的拒单流量。**只能借鉴可见补回的事件形态，列为认识数据盲区的阅读，不列为可直接复现项目。

## 三、针对现有数据的可执行研究方案

以下是我们的新实验设计，不是声称这些论文已经研究了本项目数据。

### 第一优先：队前、队后谁先跑？

来源P03/P06/P33。这个问题最能利用已经重建的逐笔FIFO，也比继续寻找整数尾数多走一步。

1. 在连续竞价时按固定钟表或固定事件数抽取位于最优档的在簿订单，不按未来是否成交来挑。
2. 用当时队列计算队前量、队后量；记录其他订单撤销或成交导致的变化。订单本身的未来结果不提前进入特征。
3. 看随后若干BBO更新或1/3/10秒内，目标单先撤、先成交还是仍在。部分成交单继续跟踪；休市/观察结束保留删失，不当成撤单。
4. 匹配同股、方向、时段、价差、价格距离、数量和已存续时间。将队前/队后扣减拆成真实成交与撤单。
5. 首先输出条件撤单率和存续曲线，再考虑简洁的竞争风险模型。没有必要一开始上复杂神经网络。

预期图：横轴为队前或队后量变化，纵轴为后续撤单率；同样总深度变化，拆分后是否出现不同关系？若对照不足就报告覆盖率，不用宽分箱制造稳定结果。

### 第二优先：盘口数量很稳，里面的订单是否一直在换？

来源P04/P05/P09/P24，以及我们自己的[332对联合报价研究](../joint_quotes/REPORT.md)。此前多数联合样本在十档外，所以本轮新题应分别报告最优档、2–10档和远档。

1. 同时记录价位总量、订单ID更替量和价格是否移动。
2. 将深度减少分成成交消耗、撤单后未补回、撤单后附近价格补回；将“成交后补单”和“撤单后补单”分开。
3. 原价补回与附近1–2 ticks补回分别统计，不把新ID强行认作同一账户。
4. 20/100毫秒及1秒窗口做敏感性分析。时间标签聚集不能被解释成真实反应延迟。
5. 事前特征只用已经发生的换单频率、时间相位及队列状态；未来补回只当结果。比较原单存续与该价位容量存续，而非只报撤单率。

预期图：同一时间轴上的总挂量、累计ID更替和真实成交量。它可以清楚展示“盘口看着没变，队列已换过几轮”，也允许结果显示某些换单确实使容量减少。

### 第三优先：成交量解释不了的跳价，是否来自盘口断层？

来源P02/P19/P36。

1. 在事件发生前保存最好两档的tick距离、最优档量、对手方深度及队列分布。
2. 划分成交消耗最优档、撤单移除最优档和其他事件。把同一可识别主动订单关联的多笔Trade聚合为一次冲击时，以冲击结束为后续观察起点。
3. 对成交量/最优档量、初始价差、同股同时间段作匹配，再比较价格位移；同时画小/大成交×小/大断层的分组图。
4. 即时位移只作机制归因；向前1/5/30秒的价格或再次跳价另作预测问题。只能用事件前的信息构造预测特征。

不要求原始市价单标签。可按实际吃过的价格档数描述“冲击激进程度”，但不声称恢复了主动单原始限价或原始申报类型。

### 第二梯队：三项值得做但需额外约束

| 题目 | 可以怎样做 | 必须避免 |
|---|---|---|
| 预测看涨，却买不进（P01/P06/P20） | 固定时点提交小额虚拟单，联合报告成交概率、等待时间和成交后有向markout | 仅挑成交赢家；将固定路径仿真当实盘；将T+1下不可完成的日内买卖记成净利润 |
| 同样深度损失，成交还是撤单更易补回（P09/P24） | 按事件前位置、初始量和价差匹配两种冲击，比较恢复到原深度所需事件数 | 把未恢复/休市删失当无限慢或普通零值；把同期反应当因果 |
| 股数不圆整，现金为什么圆整（P31/P38） | 比较修复后的总观察量与ADD剩余量，研究股数/金额聚集及板块制度约束的机械影响 | 把主板整百规定当投资者偏好；用事后恢复量回填原始申报时点；把金额公式当身份标签 |

其中markout可定义为买单`未来中间价－成交价`、卖单取相反号，分别看1/5/30秒。它是成交质量指标，不等于包含未成交机会成本、费用、库存和可交收约束的策略收益。

## 五、单日研究怎样才可信？

- 区分事件描述、向前预测、因果解释和可交易收益，不把四者混写。可可靠给出“这一天发生了什么”，不能仅凭一天证明一般市场规律。
- 识别使用频道内BizIndex，不能只按时间标签混排；保存订单关联与严格数量守恒检查。
- 连续竞价ADD可能是成交后剩余量。原始限价、完整原始类型、全成交主动单是否存在，均不能从剩余ADD随意补造。
- 不使用离线快照向未来搜索对齐作为策略信息；优先用逐笔簿。数据提供者时间标签精度不是交易者真实接收精度。
- 费用与最小tick必须进入执行解释。可预测中间价不代表跨过价差和费用后仍有利润。
- 按股票、钟表时间块报告差异及样本量；样本依赖明显时，不按每条消息独立计算极小p值。
- 上午设参数、下午检查仅提供同日稳定性。此前已经看过全天而发现的金额或周期不能再称下午独立留出。
- 一条新方向先固定规则、做一张能被反驳的图，再考虑扩模型。借鉴论文的问题与反例，不照搬海外结论或追求因子数量。
